# AI 辅助往来账对账工作流

这是一个用于核对两家公司 Excel 往来账的可复用 ChatGPT Skill。项目能够识别双方真正可比的截止日期，区分跨期入账与真实金额差异，并生成带公式、来源索引和一致性检查的 Excel 差异报告。

> 本仓库只使用虚构演示数据。真实公司名称、交易信息、联系方式及商业敏感内容均未公开。

## 解决的问题

传统 `VLOOKUP` 或简单金额匹配无法处理以下情况：

- 两份账簿截止日期不同
- 上月交易在本月补记
- 一方按折后金额入账，另一方按实际重量结算
- 磅差、手续费或退款被单独记账
- 月度汇总先截位，导致最终结果相差一分钱
- 管理汇总合并项目后，无法追溯至具体原始行

## 核心流程

1. 检查工作表、日期范围、金额字段、期初、发生额、付款和期末余额。
2. 先确定双方重叠的可比期间，再开展逐笔匹配。
3. 统一折后金额、实际金额、折扣、退款、费用和磅差等金额口径。
4. 按单号、金额、日期和业务描述依次匹配。
5. 将差异拆分为期初遗留、跨期调整和本期新增差异。
6. 对每项非零差异说明双方计算过程、具体原因和核查建议。
7. 生成管理明细、审计明细和口径核验表。
8. 通过发生额、期间桥接和同截止日期末余额进行三向勾稽。
